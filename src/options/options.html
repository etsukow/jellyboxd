Letterboxd × Seerr / Jellyfin

Connectez votre serveur Seerr (Jellyseerr / Overseerr) et votre serveur Jellyfin à Letterboxd.

Chargement…

1. Serveur Seerr / Jellyseerr / Overseerr

Incluez http:// ou https:// et le port si nécessaire.
Mode d’authentification
La clé API évite les expirations de session.
Trouvable dans Seerr sous Paramètres → Général → Clé API.
Utile pour attribuer les demandes à un utilisateur précis.

Connexion à Seerr avec un compte Jellyfin

En mode Cookie, connectez-vous une fois pour enregistrer le cookie de session Seerr. Vos identifiants ne sont jamais sauvegardés.

2. Serveur Jellyfin (optionnel)

Permet d’utiliser votre URL Jellyfin publique pour le bouton « Regarder sur Jellyfin » (au lieu de l’URL interne renvoyée par Seerr) et d’activer la recherche directe dans votre bibliothèque si une clé API Jellyfin est fournie.
